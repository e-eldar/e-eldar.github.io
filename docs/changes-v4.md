# v4 changes

## Visual fixes

- Stable hover effects on buttons, cards, links and form controls.
- Reduced aggressive transform effects that caused ugly movement on hover.
- Unified the background into `ReactBitsBackdrop`.
- Contact page no longer has a strong separator line under the header.

## Skills section

- Replaced the previous orbit-only stack visual with a cleaner skill system.
- Added icons for HTML, CSS/Tailwind, Bootstrap, JavaScript, React, Node, SQL, Auth, APIs, Java, Python, C++ and Assembly.
- Added skill level labels and improved responsive behaviour.

## Contact section

- Rebuilt the left info panel, direct contact cards, API status and contact form.
- Added better visual hierarchy and more consistent glass cards.

## Deploy

- Added GitHub Pages workflow.
- Added Netlify config.
- Added SPA fallback generation for React Router.
